# 📖 Users Management App

A **React + TypeScript + Vite** project for managing **Users** and their **Posts**, built as part of a technical task.
The project demonstrates CRUD operations, routing, and integration with the [JSONPlaceholder API](https://jsonplaceholder.typicode.com/).

---

## ⚙️ Prerequisites

Before running the project, make sure you have:

* **Node.js** (v18 or later) installed → [Download Node.js](https://nodejs.org/)
* **npm** (comes with Node.js) or **yarn** as a package manager

---

## 🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/users-management.git
cd users-management
```

2. Install dependencies:

```bash
npm install
```

---

## 🚀 Running the Project

### Development Mode (with hot reload)

```bash
npm run dev
```

Then open the app in your browser at:
👉 `http://localhost:5173`

### Production Build

Build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## 📦 Deployment

The app can be deployed easily to **Vercel**, **Netlify**, or any static hosting provider.
For Vercel:

1. Push your code to GitHub
2. Import the repo in [Vercel](https://vercel.com/)
3. Deploy → Vercel will auto-detect **Vite + React + TypeScript**

---

## 📝 Summary

* Built with **React + TypeScript + Vite**
* Uses **TailwindCSS** and **shadcn/ui** for UI styling
* Data fetched from **JSONPlaceholder API**
* Implements **CRUD operations** for Users and Posts
